# mod-110-nlp-data-engineering: NLP Data Engineering: Corpora, Cleaning, Annotation, Provenance

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 14 hours

## Learning objectives

- Collect, deduplicate (exact, n-gram, MinHash), and language-route a large multilingual text corpus
- Detect and scrub PII; apply deboilerplating and toxicity filtering with documented trade-offs
- Design annotation guidelines, calibrate annotators, measure inter-annotator agreement (Cohen / Krippendorff), and run double-annotation workflows
- Operate Argilla / Label Studio / Prodigy and use weak-supervision and active-learning loops to scale labelling
- Produce a defensible dataset card / datasheet with licensing, provenance, demographic coverage, and known-limitation disclosures
